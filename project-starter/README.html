PYTHON
Create a virtual environment and install requirements-python.txt. From student/:
  python -m jupyter nbconvert --execute --to notebook --inplace notebooks/project_analysis.ipynb
  python -m jupyter nbconvert --to html notebooks/project_analysis.ipynb
Add your chosen analysis packages with exact versions. The starter itself uses only the standard library beyond the notebook tools.

R
Install rmarkdown and knitr from your usual R package repository, plus Pandoc (bundled with RStudio). Record versions and installation instructions. From student/:
  Rscript -e 'rmarkdown::render("notebooks/project_analysis.Rmd")'
Include sessionInfo() and a versioned package list or renv.lock. Add your task's packages; Python is not required for R students.

BINARY PREDICTION CHECK (OPTIONAL; NO QUALITY SCORES)
Fill templates/evaluation_ids.csv with every expected ID and templates/expected_methods.csv with each executed method/run pair. A one-run study still needs a declared run_id (for example run01). Write results/test_predictions.csv with exact ordered columns:
  id,method,run_id,prediction,score
This starter includes run_id to support repetitions; use a different announced task schema when required. Do not submit this extra column to an existing course scorer unless that scorer supports it; create per-run files with the course's exact columns instead.
Python:
  python src/validate_predictions.py results/test_predictions.csv templates/evaluation_ids.csv templates/expected_methods.csv
R, from student/:
  Rscript -e 'source("src/validate_predictions.R"); print(validate_predictions("results/test_predictions.csv", "templates/evaluation_ids.csv", "templates/expected_methods.csv"))'
These tools check schema, duplicate/missing/extra IDs, method/run coverage, literal labels and score range. They never load true outcomes, establish model quality, detect leakage or validate interpretation. All methods in this checker use the same ID set. Different justified scopes need a registered task-specific checker. Header-only files fail by design. General task outputs are a starting schema to adapt, not an automatic binary-scoring input.
