# ECE 750 — Software Analytics

[Open the course website](https://swy351.github.io/ece750-course/)

Twelve weekly learning units connecting software research papers, traditional data analysis, LLMs and agents, and reproducible student labs. Includes 13 student notebooks, dataset downloads, and Assignment 2 and 3 handouts.

## Local preview

Run `python3 -m http.server 8000` in this directory, then open http://localhost:8000. Serve over HTTP so the browser can load course.json.

## Publication

GitHub Pages serves the root of the main branch. `.nojekyll` preserves the static files. All local asset links are relative to support the `/ece750-course/` path. Push updated files to main to republish.

## Teaching notes

Student notebooks contain instructions and TODOs, with no executed outputs. Instructor grading materials and withheld evaluation answers are excluded. Download and extract the full student lab package before running notebooks. Learning notes and progress stay in the browser; they are not submissions. Current dates and course policies remain on LEARN. Research and data provenance are linked in the weekly pages and data guide. Upstream materials retain their original terms.
